Git

  • git init - создаёт новый локальный репозиторий в текущей папке.
  • git add - добавляет изменения в индекс (подготовка к коммиту).
  • git commit - сохраняет подготовленные изменения в истории репозитория.
  • git push - отправляет локальные коммиты на удалённый репозиторий.
  • git pull - забирает изменения с удалённого репозитория и вливает их в текущую ветку.
